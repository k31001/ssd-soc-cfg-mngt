문제 — 지금의 산출물 관리가 무너지는 이유

4가지 동시 발생 문제

① 산출물 분산 (6+ 시스템)

Word · Excel · Confluence · PDF · Bitbucket · Jira · 별도 Git. cross-reference 는 사람이 추적.

② RAG/벡터DB 한계

재인덱싱 오버헤드 · 청킹 정합성 손실 · 의미 유사도 잡음 (IRQ_EN ≠ INT_ENABLE 인데 동일시).

③ MCP 토큰·latency 폭증

5–20× 토큰, 수백 ms ~ 수 초 latency, 같은 질의 → 다른 답 (인덱스 상태 의존).

④ 문서 ↔ RTL drift

RTL 변경 시 가이드·헤더·TB 따로 누락. 문서를 못 믿게 되는 단계 → 산출물 존재 의의 상실.

"Most enterprise RAG failures stem from context quality, not retrieval recall." — Unblocked, "Context Engine vs RAG"
